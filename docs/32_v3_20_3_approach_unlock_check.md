# 32. v3.20.3：靠近解锁检查与本车名称匹配加固

## 检查结果

手机设置页实际状态：

```text
[手机侧] 靠近自动解锁开关                          checked=true
[手机侧] 插充电线后禁止解闭锁                      checked=true
[手机侧] 远离自动上锁开关                          checked=true
```

当前电池状态：

```text
USB powered: true
```

服务日志：

```text
🔌 当前充电状态: 已插充电线 | 充电禁止解闭锁=true
已驻车 · 禁控保护
手机已插充电线（默认在驾驶室），禁止解闭锁
```

因此靠近解锁不是代码丢失，也不是 BLE 过滤单独导致；当前 USB 供电触发了既有的
“插线禁解”安全联锁，自动解锁被主动阻止。

## 测试方法

1. 拔掉 USB 线；或
2. 在 App「设置」页关闭「插充电线后禁止解闭锁」；
3. 再靠近本车测试。

用 ADB 连着电脑时，手机处于 USB 充电状态，默认无法测试靠近解锁。

## 本车名称匹配加固

v3.20.1 的严格过滤要求名称完全等于 `GeelyVehicle123`，如果车机广播名格式有差异，
可能误拒本车。v3.20.3 改为：

```text
名称以 GeelyVehicle 开头，且以 VIN 后三位 123 结尾
```

这样 `GeelyVehicle123`、`GeelyVehicle0123` 都能识别；其他 `GeelyVehicle*` 名称仍拒绝。

同时在识别成功时记录：

```text
🎯 本车BLE信号源: ...
```

便于确认靠近解锁使用的是哪条本车广播。
