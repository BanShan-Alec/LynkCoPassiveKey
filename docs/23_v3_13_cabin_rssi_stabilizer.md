# 23. v3.13：车内 RSSI 稳定滤波

## 一、为什么车内会 -50 / -90 乱跳？

BLE RSSI 是 2.4GHz 接收功率，车内是一个典型的**金属多径环境**：

1. **多径反射**：车身、玻璃、座椅、金属饰条把同一包信号多次反射，相位叠加/抵消；
2. **天线零点**：手机/车机天线都有方向性，手机在座椅/杯架/口袋稍微动一下就可能落进零点；
3. **人体遮挡**：身体、腿、座椅吸收 2.4GHz，手握住手机也会掉 10~20 dB；
4. **BLE 信道跳频**：37/38/39 广播信道与数据信道频率不同，多径衰落也不同；
5. **GATT 与广播混用**：连接前读的是广告 RSSI，连接后读的是 GATT `readRemoteRssi()`，两者本来就不是同一测量；
6. **车内干扰**：车机 Wi-Fi、无线充电、行车记录仪、手机热点等。

所以 `-50 → -90` 在车内是**物理上合理**的，不是车机坏了。问题在于旧滤波把这种瞬时跳变直接传给了“有效信号”。

## 二、旧滤波为什么不够稳

旧逻辑：

```text
Kalman q=0.08
+ 非对称 EMA: 上升 alpha=0.48 / 下降 alpha=0.16
```

- 上升 0.48 非常快，-50 的尖峰一下就把有效值拉高；
- 没有中值/异常点剔除，单个 -90 也会把值往下拽；
- 没有变化速率限制，所以 UI 上有效值跟着原始值抖。

## 三、v3.13 车内稳定模式

### 触发条件（满足任一）

- 手机有线充电（`wiredCharging`）；
- 车辆状态 `行驶中`；
- `evaluateInCarOrDrivingState()` 判定在车内/行车；
- 银河蓝牙已连接（`isEffectivelyConnectedToCar()`）。

### 处理链

```text
原始 RSSI
→ 4 秒滑动窗口（最多 15 个样本）
→ 中值 median
→ 偏离 median > 8 dB 时钳到 median ± 8 dB
→ Kalman q=0.02, r=2.20
→ 对称 EMA alpha=0.18
→ 变化速率限制 10 dB/s
→ effectiveDbm
```

对比：

| 参数 | 旧 | 车内新 |
| :--- | :--- | :--- |
| 异常点 | 无 | 中值 + ±8 dB 钳位 |
| Kalman q | 0.08 | 0.02 |
| EMA | 0.48 上升 / 0.16 下降 | 0.18 对称 |
| 最大变化率 | 无 | 10 dB/s |

车外仍保留旧的快速跟踪（40 dB/s），避免靠近解锁变慢。

### 结果

- **原始信号**仍会 -50/-90 跳（这是物理测量，应该保留）；
- **平滑/有效信号**不再跟着尖峰跳，阈值线稳定；
- 自动解锁/上锁使用稳定后的 effectiveDbm；
- 日志会打印一次：

```text
📶 进入车内稳定滤波 (4s中值窗口/异常限幅/低增益/限速)
```

因为现在手机通过 USB 连着电脑，`wiredCharging=true`，一有 RSSI 样本就会进入车内模式；需要实车看 `原始` 与 `有效` 的对比。

## 五、调参边界

- 如果有效值仍然跳：把窗口从 4s 加到 6s，或把限速从 10 dB/s 降到 6 dB/s；
- 如果靠近解锁变慢：把限速提高到 15~20 dB/s，或窗口降到 2.5s；
- 如果车外也过于稳定：检查是否因为充电/车机连接误触发 cabin 模式；
- 原始值不应被“美化”，它用于诊断多径/天线问题；稳定的是 effective。
