# 33. v3.20.4：锁屏靠近解锁排查

## 锁屏本身会不会阻止解锁

不会。`KeyRadarService` 没有用 `KeyguardManager` 或“屏幕必须点亮”来拦截解锁；
锁屏时仍由前台服务 + BLE 扫描 + PARTIAL_WAKE_LOCK 执行阈值判断。

当前手机设置：

```text
靠近自动解锁开关：开
远离自动上锁开关：开
插充电线后禁止解闭锁：开
距离传感器揣兜补偿：关
USB powered：true
```

## 会阻止靠近解锁的场景

1. **手机插着 USB/充电线**：`插线禁解` 开启时直接 `禁控保护`。当前就是此状态。
2. **靠近自动解锁开关被关闭**。
3. **刚执行过锁车/解锁命令**：10 秒冷却；同方向 20 秒内不重复触发。
4. **车况被判“行驶中”**：GPS 速度、旧通知栏“行驶中”、或旧车况帧。
5. **手机在口袋且遮挡补偿关闭**：有效 RSSI 达不到 `-63 dBm`。
6. **当前锁态被记为“已解锁”**：不会重复下发解锁；无本车信号 20 秒后才回退未知。
7. **银河已占用 BLE 连接**：车机停止广播后可能没有广播 RSSI；锁屏久了更依赖 GATT/心跳。
8. **锁屏超过 5 分钟且车辆不在附近**：`PARTIAL_WAKE_LOCK` 会释放；只剩 90 秒扫描心跳，
   OEM 深度休眠时可能变慢或漏掉第一次靠近。
9. **本车广播身份不匹配**：v3.20.3 已放宽为 `GeelyVehicle` + VIN 后三位。
10. **蓝牙关闭、权限/电池白名单被重置、通知监听被关闭**。

## 已验证项

- 前台服务运行中；
- 蓝牙扫描/连接、定位、通知权限均 granted；
- 通知监听服务已启用；
- Doze 白名单已包含本 App；
- 当前自动解锁开关为开。

## v3.20.4 修复

通知栏的旧“行驶中”原来没有时效，停车后可能永久阻止解锁。现在只接受 **90 秒内**的
通知状态；超时后不再作为禁控依据。

同时保留 v3.20.3 的本车名称匹配加固和 `🎯 本车BLE信号源` 日志。

## 建议

- 测靠近解锁前先拔 USB，或关闭“插充电线后禁止解闭锁”；
- 口袋场景开启“距离传感器遮挡补偿”；
- 如果仍失败，抓 `🎯 本车BLE信号源` 和 `未触发` 附近日志。
