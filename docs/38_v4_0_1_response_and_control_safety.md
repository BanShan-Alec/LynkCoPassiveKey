# 38. v4.0.1：接近响应、离开上锁与单次发送优化

版本：`4.0.1-min / versionCode 101`。默认参数继续使用 `-75 dBm / -82 dBm / 4.5 s`，升级不重写已有阈值或车辆身份。

## 1. 改动

1. **分离官方就绪与 GATT 测距连接**。官方通知连接边沿立即通知主服务；只有官方就绪才共享 GATT。回调在同一主线程处理，旧 GATT 实例、旧地址 ACL 断开、旧通知版本和旧监听实例不能修改新连接。
2. **降低滤波滞后**。三点中值和单层按时间计算的 EMA 替代 Kalman+EMA 串联；接近350ms、远离750ms时间常数，三秒断档后重置。扫描去除过期、重复、乱序结果；GATT500ms仅一个在途读取，停更后恢复通道。
3. **接近与离开使用不同补偿**。遮挡稳定800ms后仅接近信号加8dBm；离开及近场保护保持真实滤波值，避免原始-85被当作-77而不锁。
4. **近场保护与驻留并行**。默认六秒近场保护仍然生效，但不再每次清空远场4.5秒倒计时。必须满足两个条件和至少三个新样本；三秒断档、返回缓冲带或禁控都阻止上锁。
5. **统一发送与反馈**。只有主服务持有一条待发请求，固定十二秒期限。对应通知按钮就绪立即尝试，明确未发送时每秒至多重试，每条请求至多两次；每次接近、每个动作最多两条请求。选择PI或View其一，不再叠加DK1.5广播。成功停止重发；未知异常停止并提示核实，不把未知写作成功。
6. **锁后回程保护**。已经上锁后，口袋补偿不能把-83/-81附近抖动变成新接近。官方仍连接时，要求未补偿信号回到默认-78以上并持续一秒；失败预算耗尽时也必须先连续远场八秒再真实返回，避免无限重发及永久卡死。真正断连并离开足够久后结束旧会话，保留下一次官方先连接时的即时解锁；新鲜远场仍然拦截。
7. **日志有界且分离**。UI最近十条关键事件；`passive_key.log`及`.1`—`.3`各64KiB，诊断文件及`.1`各64KiB，合计384KiB。扫描/遮挡/周期RSSI不消耗关键事件文件；一键清空通过同一写入线程清理全部分段。

保留服务总开关、插USB/AC线禁控、行驶禁控、断连不误锁、自动身份学习与自定义阈值。没有引入新的用户设置或逆向私有数据依赖。非vivo的官方五秒远距连接分支仍只记录，未改写注入的RSSI。

## 2. 离线回放

沿用排查文档37的合成输入：稳定原始信号三十秒，靠近场景从-95切换为-63；离开场景从-60切换为-85。离开预热阶段显式确认解锁请求已发送。表中只统计状态机产生请求的时刻，不包含官方鉴权、无线发送和车锁执行时间。

| 采样间隔 | 旧版接近 | 新版接近 | 旧版离开，未补偿 | 新版离开，手持/口袋 |
| --- | --- | --- | --- | --- |
| 250ms | 2.75s | 0.75s | 14.75s | 7.00s / 7.00s |
| 500ms | 5.50s | 1.00s | 19.00s | 7.00s / 7.00s |
| 1000ms | 11.00s | 2.00s | 29.00s | 8.00s / 8.00s |

旧版口袋场景持续原始-85，在60秒回放内没有上锁请求；新版与手持使用相同距离判定。该结果证明算法路径已改善，不等于实车保证一秒解锁或某个固定米数上锁。

## 3. 自动验证

```bash
SKIP_INSTALL=1 bash GeelyKeyRadarApp/build.sh
```

构建运行五组纯Java测试，然后完成aapt2、javac、d8、对齐和签名：

- `PassiveKeyLogicTest`：单次接近、近场保护、连续驻留、断档、行车禁控、失败保留/有限恢复、锁后边界抖动、真实返回、旧远场与官方就绪；
- `RssiPipelineTest`：250/500/1000ms采样下的原始RSSI→滤波→请求，手持/口袋对照，单帧强包、两秒车内深衰落、恰好到阈值、乱序/重复/非法样本；
- `PendingControlTest`：官方3.1秒就绪即时领取请求、只完成一次、固定十二秒期限、旧序号取消、两次尝试上限；
- `NotificationEpochTest`：旧解析、新通知、移除顺序、监听重绑、活动通知为空后旧快照不能复活；
- `RotatingFileLogTest`：固定文件数与大小、诊断噪声不挤掉动作、轮转保留近期历史、清空全部分段。

上述是离线测试，无法代替Android系统真实回调、厂商ROM保活和车辆鉴权联调。

## 4. 实车验证

本次构建阶段手机ADB已经断开，尚未安装此版本或完成实车验证。连接恢复后先覆盖安装并检查服务/通知使用权及插线禁控，再验证：

1. 息屏手持和口袋各做两次靠近/离开，检查实际距离和是否只发送一次；
2. 车内插USB线期间不发任何锁/解请求，停车拔线后靠新样本正常进入远离确认；
3. 车旁短时遮挡、绕车尾及两秒弱信号不锁车；锁后在远场边界停留不能反向解锁；
4. 官方先连接并停广播时，通知就绪仍被处理，随后GATT持续给出新鲜RSSI；
5. 关闭服务总开关、关闭单项自动开关或重新插线，等待中的请求立即取消；
6. 一次发送超时后再次真实远离/返回，可以恢复；未知发送结果显示提示且不自动重复。

出现异常应同时取关键日志及诊断日志，核对`raw/smooth/approach/pocket/age/source/official/gatt/dwell/samples/wiredBlock/driving/pending`与请求序号。界面“指令已交付”不代表已经拿到车锁执行回执。
